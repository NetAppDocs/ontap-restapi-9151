= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
Establish and manage SVM peering relationships using these endpoints to facilitate communication and resource sharing between storage virtual machines.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}
