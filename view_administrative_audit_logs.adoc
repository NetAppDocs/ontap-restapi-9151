= View administrative audit logs
:imagesdir: ./media/

[.lead]
Use these endpoints to view administrative audit logs, retrieving detailed records such as timestamps, node names, and indexes. Accessing audit logs helps you track and analyze system activities for security and compliance purposes.

== Overview

These APIs return audit log records. The GET requests retrieves all audit log records. An audit log record contains information such as timestamp, node name, index and so on.
 +

'''
