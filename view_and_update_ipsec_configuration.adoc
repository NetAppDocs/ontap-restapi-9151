= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Retrieve and modify IPsec configurations to manage secure communication settings within your network. Use these endpoints to check and update the IPsec status as needed for maintaining security standards.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
