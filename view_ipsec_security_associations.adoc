= View IPsec security associations
:imagesdir: ./media/

[.lead]
Access IPsec security associations to examine the details of encrypted connections in your network. Use these endpoints to retrieve information about existing security associations, ensuring effective management and troubleshooting of IPsec configurations.

== Overview

* Collection Get: GET security/ipsec/security-associations
* Instance Get: GET security/ipsec/security-associations/uuid
