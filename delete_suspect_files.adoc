= Delete suspect files
:imagesdir: ./media/

[.lead]
Remove suspect files from a volume using the suspects DELETE API. Use these endpoints to clear identified files from the list of potential suspects.

The suspects DELETE API clears all the suspect files for a volume from the list of potential suspects.
